# Legal AI Service

Юридический ИИ-ассистент с веб-интерфейсом на React и серверной частью на FastAPI.

**Рабочий сайт:** [135-106-163-146.nip.io](https://135-106-163-146.nip.io).

## Возможности

- Консультации в чате, история переписки и потоковая выдача ответов.
- Загрузка файлов и подготовка документов.
- Отслеживание изменений законодательства и уведомления, связанные с использованными нормами.
- Аккаунты пользователей, согласие на обработку данных и административная панель.

Ответы ИИ носят информационный характер и не заменяют консультацию юриста.

## Локальный запуск

Нужны Docker с Compose и Node.js с npm. Создайте `backend/.env` на основе `backend/.env.docker.example`. Задайте собственный `SECRET_KEY`; для ответов модели настройте учётные данные GigaChat по параметрам в `backend/app/core/config.py`. Не добавляйте секреты в Git.

Запустите серверную часть:

```sh
cd backend
docker compose up -d --build
```

В другом терминале из корня проекта:

```sh
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Запросы `/api` Vite направляет на `http://127.0.0.1:8000`. Проверка backend: `http://127.0.0.1:8000/health`.

Локальный Compose и конфигурация рабочего сервера отличаются. Для production используйте [инструкцию по развёртыванию](docs/deploy-notes.md).

## Проверки и сборка

Из каталога `frontend`:

```sh
npm run type-check
npm run build
```

Готовый интерфейс находится в `frontend/dist`. По умолчанию он обращается к `/api` того же сайта; при отдельном API задайте `VITE_API_BASE_URL` до сборки.

## Вход и документы аккаунта

При открытии приложения сохранённая сессия проверяется через `/auth/me`. Пользователь с действующей сессией при переходе на страницу входа попадает в чат или на страницу согласия.

«Запомнить меня» сохраняет токены в `localStorage`; без галочки используется `sessionStorage`. При выходе токены удаляются. В меню аккаунта доступны политика конфиденциальности и обработки персональных данных, а также пользовательское соглашение.

## Публикация

Текущий сервер — `135.106.163.146`, подключение: `ssh root@135.106.163.146`.

Интерфейс обслуживает Nginx из `/var/www/legalai-service`, запросы `/api` направляются на backend. Рабочий Compose-проект находится в `/opt/legal-ai/backend` и использует серверный override-файл.

**Отправка кода в GitHub не обновляет сайт автоматически.** Интерфейс публикуется отдельно: сборка, резервная копия, загрузка файлов, проверка. Точные пути, сценарий публикации и откат описаны в [docs/deploy-notes.md](docs/deploy-notes.md).
