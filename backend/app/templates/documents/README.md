# Тексты шаблонов

Каталог сценариев и полей находится в `services/document_scenarios.py`.
Подключены 32 самостоятельно подготовленных текстовых пакета по открытым
формам и нормативным требованиям. Их статус `source_checked_draft`:
это не юридическая экспертиза и не коммерческие выгрузки ГАРАНТа.
Источники и ограничения находятся в пакетах и в
`artifacts/document_templates_2026-10-24/manifest.json`.

После получения и проверки текста добавьте `<scenario_key>.json`:

```json
{
  "scenario": "pretense_debt_loan",
  "version": 1,
  "source": "Источник текста или указание собственного авторства",
  "usage_basis": "Основание использования текста в сервисе",
  "review_status": "lawyer_reviewed",
  "reviewed_by": "Кто выполнил юридическую проверку",
  "reviewed_at": "2026-10-24",
  "blocks": [
    {"role": "addressee", "text": "Кому: {{recipient}}\nАдрес: {{recipient_address}}"},
    {"role": "addressee", "text": "От: {{sender}}\nАдрес: {{sender_address}}"},
    {"text": "Здесь размещается проверенный текст с полями {{amount}} и {{facts}}."}
  ]
}
```

Это пример формата, а не юридическая форма. Не копируйте его в рабочий пакет.
Для самостоятельно адаптированного текста без проверки юристом используйте
`source_checked_draft`, `checked_at` и пустые `reviewed_by`/`reviewed_at`.
Статус `lawyer_reviewed` без имени проверяющего и даты не принимается.
Роли блоков управляют шапкой, заголовками, разделами и подписями в DOCX/PDF.
Допускаются только поля соответствующего сценария. Условные блоки содержат
`when_field` и `when_value`: блок подключается только при точном совпадении
заполненного значения. Неизвестный ответ не активирует условие.
Общие части можно повторно использовать при подготовке пакетов; юридические
основания разных видов споров должны оставаться отдельными.

Пакет фиксируется в JSON состояния при выборе сценария. После обновления
библиотеки уже начатые документы используют прежнюю версию. Для новой версии
нужно начать новую подготовку. Проверка JSON не заменяет юридическую проверку.
