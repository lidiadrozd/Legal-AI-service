Russian Trusted Root CA
Source: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
Instructions: https://developers.sber.ru/docs/ru/gigachat/certificates
Downloaded over verified HTTPS on 2026-10-09.

Public CA certificate, not a private key. Used only by the GigaChat HTTP client.
GIGACHAT_CA_BUNDLE_FILE overrides the path, including inside Docker.
The default path is resolved relative to the backend directory.
Ordinary public CAs and hostname verification remain enabled.
Review and refresh the certificate before expiration; do not disable TLS verification.
