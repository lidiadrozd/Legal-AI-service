ТК РФ, статья 81, часть 1, пункт 5. Увольнение по инициативе работодателя.

Краткое изложение, не дословный текст закона: одним из оснований выступает повторное нарушение работником своих трудовых обязанностей без уважительных причин при наличии дисциплинарного взыскания. Пояснение: неоднократные опоздания требуют проверки именно условий этого основания и процедуры взыскания; они не превращают увольнение работодателем в увольнение по собственному желанию по статье 80 ТК РФ. По одному сообщению об опозданиях нельзя признать увольнение законным: необходимо проверить факты, взыскание и соблюдение установленной процедуры.
