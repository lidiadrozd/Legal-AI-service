# Версия генератора документов от 6 ноября 2026 года

В основе этой версии — сохранённый локальный код утра 5 ноября. В него внесены исправления извлечения данных и повторных вопросов. Интерфейс сохраняет удаление режима «Встроенный шаблон» и показателя уверенности в обычных ответах.

## Поведение

- Длинное начальное сообщение и подробный ответ на один вопрос могут заполнить сразу несколько полей: стороны, адреса, предмет, сроки, цену, оплату, материалы и приёмку.
- При личном подписании известные имена сторон используются для подписей. Явное указание заполнить реквизиты вручную учитывается при выборе следующего вопроса.
- После напоминания «уже писала» сведения повторно проверяются по истории. Если поле всё ещё неоднозначно, предлагается уточнить именно его или оставить для ручного заполнения вместо бесконечного повторения общего вопроса.
- Вызовы модели ограничены по времени. Сохранённый ответ можно обработать повторно; команда «повтори» после ошибки не должна давать пустой ответ.
- Частичные возвраты займа сохраняются отдельно от исходной суммы. Повтор одного платежа не уменьшает остаток второй раз. При неизвестном годе платежа запрашивается год; договорная дневная неустойка рассчитывается по периодам изменения задолженности.
- При подготовке текста договора отбрасываются служебные инструкции редактору и неподтверждённые условия. Известные сведения о покупке сохраняются даже при неполной дате.

## Проверка

Пройдены 183 регрессионные проверки: договоры работ и услуг, потребительские претензии, займы, апелляция, доверенность, работа диалога и расчёты. Дополнительно через настоящий GigaChat проверен подробный пример ремонта комнаты до формирования DOCX. Неуказанные условия в проверочном документе явно оставлялись для ручного заполнения. Это проверка конкретных сценариев, а не гарантия отсутствия ошибок во всех формулировках.

Для чистого сравнения поведения рекомендуется новый чат. Локальные настройки, ключи API, история переписки и пользовательские документы в эту поставку не включены.

Запуск описан в `docs/team_handoff.md`. Для локального интерфейса с прокси Vite используйте `VITE_API_BASE_URL=/api`; прокси направляет запросы на `127.0.0.1:8000`.
