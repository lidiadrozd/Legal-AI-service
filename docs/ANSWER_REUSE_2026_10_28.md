# Повторное использование ответов в документе

Проверены диалог и DOCX по взысканию долга за разработку сайта. Изменения
внесены в сбор данных и редактор, исходный файл пользователя не изменялся.

Причины повторов:

- «Стоимость» ошибочно сопоставлялась с основной задолженностью, в том числе
  когда пользователь отвечал о договоре. Ответ о договоре при этом пропускался.
- Аванс из ответа о выполнении услуг не сохранялся как фактическая оплата.
- Поиск вопросительных слов находил «какие» внутри слова «никакие».
- «Суд не определён» сохранялся как предполагаемое название суда.

Исправления:

- Цена договора, аванс и остаток долга сохраняются отдельно с цитатами.
  Извлечение данных из чужого поля не перезаписывает уже известную сумму.
- Один ответ может заполнить договор, приёмку, оплату и срок. Для каждого
  поля сохраняется соответствующая часть сообщения, а не весь ответ целиком.
- Для подтверждённого требования только основного долга формируется расчёт
  и цена иска. Дополнительные начисления не добавляются без заявления.
- В просительной части используется типизированная сумма и действие взыскания.
- Для организации вопрос о реквизитах касается ИНН и ОГРН, а не рождения.
- Редактор отклоняет бытовые сокращения и неотредактированные строчные
  предложения; служебное название поля не дописывается к ответу.
- Исправлено перечисление «договор, акт и переписка», оформление контактов
  и точной пары даты и места рождения.

Проверки: общая регрессия — 492 пройденных теста; после окончательной правки
редактора — ещё 111 проверок соответствующих компонентов. Реальный GigaChat
прошёл тестовый диалог из 22 сообщений до файла, без непроверенных редакций.
DOCX отрисован в Microsoft Word, обе страницы просмотрены. Пакетный renderer
диагностирован: в Windows отсутствует soffice.exe, поэтому применён Word.

Файлы проверки: `artifacts/answer-reuse-final-tests.txt`,
`artifacts/answer-reuse-last-checks.txt`, `artifacts/answer-reuse-live-final.txt`.
Тестовая копия: `artifacts/answer-reuse-qa/service-claim.docx`.
Поля неизвестного суда и непроверенной пошлины остаются видимыми; файл
не объявляется готовым к подаче только по факту его создания.
