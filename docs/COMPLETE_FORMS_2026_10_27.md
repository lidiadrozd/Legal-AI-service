# Расширение составителя на 40 форм — 27.10.2026

Сохранены две ранее настроенные формы: трудовая жалоба и иск об алиментах
в твёрдой сумме. Остальные 38 форм переведены на `clause_document`:
неизменяемую структуру DOCX, отдельные реквизиты, целевые абзацы,
условные разделы и нормативный профиль конкретного обращения.
Полный перечень с макетами: [TEMPLATE_EXPANSION_40.md](TEMPLATE_EXPANSION_40.md).

## Границы ответственности компонентов

- `document_form_rules.py`: правовые профили, происхождение ссылок,
  основания льгот, цена иска и поля, требующие проверки.
- `document_form_composition.py`: редактура отдельных ответов, сохранение
  участников, отрицаний, сумм и доказательств; модель не перестраивает документ.
- `document_form_intake.py`: несколько ответов в одном сообщении,
  явные отрицательные ответы, контакты и подпись без повторного сбора фактов.
- `document_docx_template.py`: заполнение готового DOCX с сохранением
  таблиц, полей, нумерации и разметки. Исходные версии макетов не перезаписываются.

Простые официальные ответы обрабатываются локально. Для разговорных фрагментов
редактор получает выбранный вид документа и только соответствующие исходные
данные. После проверки чисел и смысла выполняется независимая проверка редакции.
Если редакция не прошла проверку, файл остаётся доступным как черновик с именованным
полем для проверки; исходный ответ сохранён. Повторная подготовка не подменяет его.

Суммы, записанные моделью словами, приводятся к исходным цифрам только при точном
совпадении числового значения и единиц. Даты и идентификаторы по этому правилу
не угадываются. Фрагменты JSON и служебная разметка не считаются официальным текстом.

## Проверка

- Общая регрессия документов: 479 тестов пройдено.
- После окончательной правки макетов: 259 проверок форм, DOCX, API и составителя
  пройдено; результат в `artifacts/complete-forms-layout-tests.txt`.
- Все 38 форм заполнены вымышленными данными, скачаны через тестовый API,
  преобразованы серверным LibreOffice в PDF; страницы просмотрены.
- Представительные макеты дополнительно проверены в Microsoft Word: иск об
  алиментах с формулой цены иска, потребительский иск и договор займа.
- Живые проверки редактора используют только вымышленные примеры. Их результаты
  фиксируются отдельно в `backend/tests/complete-forms-qa/live/report.json`.

Это проверки программы и макетов, а не юридическая экспертиза любой ситуации.
Неизвестный суд, реквизиты, применимость процессуального порядка, спорный расчёт,
госпошлина или региональный показатель сохраняются как вопросы для проверки.
Ни одна форма не помечена как проверенная юристом. Поддержка ограничена каталогом;
нетипичный случай нельзя автоматически считать подходящим под ближайшую форму.
