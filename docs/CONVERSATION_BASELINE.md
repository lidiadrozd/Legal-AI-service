# Версия общения, одобренная пользователем 25 октября 2026 года

Пользователь отметил, что ему значительно больше нравится нынешнее общение,
и попросил сохранить эту версию до исправлений выдачи файлов и классификации.

Контрольная копия исходников: `artifacts/checkpoints/conversation-2026-10-25-before-fixes.zip`.
Рядом сохранена контрольная сумма SHA-256; внутри архива — хеши отдельных файлов.
Это копия поведения на момент одобрения, включая известные на тот момент ошибки.

Что сохранять при последующих изменениях:

- Один текущий вопрос; ответы обычным языком.
- Содержательные пояснения без потери текущего шага.
- Сохранение фактов и истории пользователя.
- Возврат к заполнению после пояснения; никакой самовольной смены режима.
- Скачиваемый файл в чате вместо полного текста документа.

Как вернуться к копии по явному запросу пользователя:

1. Сначала сохранить отдельную копию текущих исходников.
2. Проверить SHA-256 архива и распаковать его в отдельную папку.
3. Восстановить из него исходники приложения, конфигурацию сборки и тесты.
4. Пересобрать интерфейс и перезапустить API.
5. Повторить проверки заполнения, пояснения и скачивания файла.

В архив не входят ключи `.env`, базы данных, загруженные документы и личные
файлы пользователей. Восстановление кода не предполагает удаления этих данных.
Не считать эту заметку разрешением выполнять откат без запроса пользователя.
