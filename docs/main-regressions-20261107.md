Исправлены восстановление сессии через getMe, соблюдение «Запомнить меня»,
удаление старой постоянной копии токенов, переход с /login для уже вошедшего

Добавлен исполняемый тест состояния хранилищ, восстановления сессии и баннера.

Фраза «Договор заключён на неопределённый срок» больше не распознаётся как
отсутствие ответа. Существующие тесты экспорта трудового договора проходят;
добавлены отдельные проверки сохранения этого факта и распознавания неизвестных
ответов.

Для хешируемых текстов закреплены LF в .gitattributes, для исходных бинарных
форм отключены преобразования текста. Контрольные суммы двух трудовых норм
пересчитаны для байтов, уже находившихся в Git: старые суммы соответствовали
CRLF-копиям. Содержание норм не менялось. Добавлена проверка всех записей
legal_sources.json; строгая проверка хешей в приложении сохранена.

Устаревшие ожидания тестов согласованы с поведением выпуска 6 ноября:
52 публичные формы / 55 сценариев; отсутствие показателя уверенности;
автоматическое заполнение подписи известным ФИО. Тест помощи использует
завершённую покупку с датой, чтобы проверять сохранение состояния, а не запуск
новой проверки недостающей даты. Сценарии многофактных ответов проверяют работу
при недоступной дополнительной модели (RuntimeError) вместо запрета самой
попытки обращения к ней. Проверки извлечённых значений, последовательности
вопросов и содержимого документа сохранены.
