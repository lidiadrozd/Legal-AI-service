## Когда создаётся связь для уведомлений

Пользователь и вся переписка сохраняются в обычных таблицах независимо от цитат. ChatLawReference — отдельная связь сообщения с распознанной нормой:

- Нет определённого закона — связи для мониторинга нет. Запись с пустыми законом и статьёй не создаётся: её невозможно сопоставить с поправкой.
- Известен закон без статьи — поддерживаемая однозначная ссылка может сохраняться со статьёй ""; это связь со всем законом, а не неизвестная статья. При совпадении конкретной поправки такое предупреждение будет шире, чем для одной статьи.
- Закон и статья определены — сохраняется точная связь; по возможности также часть/пункт.

NULL не вводился: текущая схема и сравнение областей используют пустую строку. Миграция ради переименования отсутствующего значения не нужна. Сохраняется только распознаваемая ссылка ассистента в его ответе; простое упоминание пользователем само по себе не создаёт такую связь.
